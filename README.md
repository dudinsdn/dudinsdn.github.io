# Priangan Signal Lab

Personal portfolio for Dudin, focused on electronics, IoT, backend engineering,
AI experiments, and creative technology.

## Design

The visual system combines West Java topographic field notes with modern
engineering diagrams. A signal route connects the site's core disciplines:
physical devices, backend systems, intelligent processing, and useful output.

## Stack

- Semantic HTML
- Modern CSS
- Vanilla JavaScript
- GitHub Pages

No build step or package installation is required. Open `index.html` directly
or serve the directory with any static file server.

## Content

Contact details and featured work are maintained in `index.html`.
Theme behavior, navigation, scroll reveals, and the WIB clock live in `assets/js/script.js`.

CSS is organized by responsibility:

- `assets/css/style.css` contains the visual foundation, layout, and components.
- `assets/css/animations.css` contains reveal behavior and keyframes.
- `assets/css/responsive.css` contains breakpoints and reduced-motion overrides.
